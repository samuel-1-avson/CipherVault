Connect your CipherVault account

        
      

      

        

          Production account enrollment is signed by the account key and the current vault device. The key stays in your OS keystore; the browser never receives it.
        

        
Run this from the CipherVault repository that contains your vault. The command signs a short-lived browser handoff locally and prints a one-time production link; open that link to finish sign-in and enroll your passkey or authenticator:

        
ciphervault auth connect --endpoint https://vault.cipherv.online/api/account

        
If the command is unavailable, install the latest release with the official installer, or run ciphervault update.
