The Four Critical Secrets Failure Modes

Git tracks source code. Once secrets are excluded by .gitignore, developers face four systemic vulnerabilities:

CRISIS #01 Accidental Git Leaks

One careless git add . or an overlooked staging commit permanently pushes API tokens, JWT private keys, and DB connection strings directly to public git mirrors.

CIPHERVAULT SHIELD:

Secrets are tracked in a sealed, hardware-backed out-of-band ledger that Git never touches.

CRISIS #02 The Clean-Machine Wipe

When a laptop is lost, damaged, stolen, or wiped, Git only restores code. Days are lost manually resetting unbacked local .env files and private certificates.

CIPHERVAULT SHIELD:

Reconstruct your complete secret tree on a virgin machine in 30 seconds using an offline paper kit or Shamir guardians.

CRISIS #03 Centralized SaaS Lock-in

Centralized vaults introduce third-party custodial risk, vendor outages, internet dependencies during local builds, and recurring monthly per-seat API fees.

CIPHERVAULT SHIELD:

100% self-hosted, sovereign, and peer-replicated. Zero vendor dependencies, zero recurring license fees.

CRISIS #04 Plaintext Disk Residue

Leaving plaintext .env files sitting on SSDs exposes secrets to malicious npm dependency post-install hooks, malware, and shoulder surfers.

CIPHERVAULT SHIELD:

Zero-disk execution (ciphervault run -- npm start) decrypts secrets strictly in process RAM with zeroize scrubbers.

Developer Working Tree Enrollment

CRYPTOGRAPHIC & ARCHITECTURAL MECHANICS:

CipherVault tracks secret files completely out-of-band from Git. During enrollment via ciphervault track .env, the file is hashed with BLAKE2b-256, and metadata is recorded in an encrypted local SQLite WAL ledger (.ciphervault/state.db). The Git working tree and .gitignore remain completely untouched.

SECURITY INVARIANT GUARANTEE:

Guarantees zero accidental staging into Git commits (git add . will never expose secrets). Host OS hardware keyrings (Windows DPAPI, macOS Keychain, Linux Secret Service) seal the vault master key R.

pub fn enroll_secret_file(path: &Path) -> Result<TrackedMetadata> {

    let cid = blake2b_256(&raw);
