**Scope:** `apps/cli` — Clap CLI (`src/main.rs`, `src/commands/*`, `src/util.rs`, `src/diff.rs`, `src/dotenv.rs`) with focus on the interactive TUI (`src/tui/app.rs`, `ui.rs`, `events.rs`, `mod.rs`).
**Method:** static read of all four TUI modules + CLI entry, `grep` for panic-safety/secret handling, `cargo test -p ciphervault-cli --bin ciphervault tui`, `cargo clippy -p ciphervault-cli`.
**Verdict:** ship-shape. Non-blocking architecture is correct, terminal lifecycle is correct, 43/43 TUI tests pass, clippy clean, zero `unsafe`/`todo!`/`panic!` in TUI. Main gaps are destructive-key confirmations, a wrong per-snapshot file count, missing confirmation/search affordances, and accessibility (color-only + no `NO_COLOR`/minimum-size guard).

## Architecture — why it works

1. **Correct terminal lifecycle** (`tui/mod.rs:17-55`): `stdin.is_terminal()` guard with a clear bail message → `enable_raw_mode` + `EnterAlternateScreen` → `hide_cursor` → panic hook that restores raw mode + leaves alt screen before delegating to the original hook → clean restore on exit (`disable_raw_mode`, `LeaveAlternateScreen`, `show_cursor`). This is the right order; many TUIs forget the panic hook.
2. **Never-block event loop** (`tui/mod.rs:58-111`): 50 ms tick, `event::poll(timeout)` + single `event::read`, then `app.drain_tasks()`. One-shot update check on first tick, periodic `spawn_operator_poll` + conditional `spawn_explorer_refresh` gated by `last_poll >= poll_interval`. Comment at `mod.rs:95-107` explicitly notes the timestamp advances at *spawn* time with duplicate-spawn guards, so a slow operator can't stack ticks — correct.
3. **Background-task fan-in** (`tui/app.rs:260-280, 408-418, 1114-1322`): every network/PC-SC/chunk/update/push/anchor task runs inside `tasks: JoinSet<TuiTaskOut>` behind a `*_in_flight` boolean (poll, explorer, token, object-probe, push, anchor, update, inspect-index). `drain_tasks` applies completions via `apply_task_out`. `have_runtime()` (`app.rs:19-21`) makes spawns no-op without a Tokio runtime so plain-thread unit tests can construct `TuiApp` — a thoughtful testability seam.
4. **Honest states, not false negatives**: `polls_completed == 0` renders `POLLING…`/`PROBING` instead of `OFFLINE` in both the header badge (`ui.rs:107-124`) and operator rows (`ui.rs:558-579`); token tab distinguishes `Probing…` / `PIV token attached` / `No PIV token`; FastCDC has a `fastcdc_notice` for cap-skips vs. genuinely-empty. Tests pin each of these.
5. **FastCDC inspector is the real chunker** (`app.rs` + `ui.rs:719+`): boundary-kind column (`S`/`L`/`max`/`tail` with `boundary_color`), gear fingerprint, entropy, duplicate detection, `MAX_INSPECT_BYTES = 64 MiB` cap (`app.rs:15`), `InspectCacheKey { path, size, mtime }` so back-navigation is free, `spawn_blocking(compute_inspection)` off the UI thread.

## Findings

### P1 — fix before calling it done

- **P1-1 Snapshot `files_count` is wrong.** `app.rs:636` sets `files_count: tracked_count` (the *current* tracked-file count) for *every* historical snapshot row. History always shows today's count. Fix: store per-snapshot manifest file count at `list_snapshots` mapping time (or rename the column to "Files now" until then). Ref: `app.rs:582-641`.
- **P1-2 No confirmation on costly/destructive keys.** `p` (push→replicate), `a` (anchor→Arbitrum L2 tx), `x` (untrack) fire on a single keypress with no confirm modal (update is the only guarded one, `events.rs:105-118`). Anchor costs real gas; untrack surprises. Fix: reuse the update-modal pattern — small `[Y]es/[N]o` confirm for `a` and `x`, and optionally `p`.
- **P1-3 Track modal does blocking I/O on the input thread.** `events.rs:34-56` calls `get_vault_store()` → `track_file()` synchronously inside `handle_key_event`. Every other expensive path uses `spawn_*`; this one can stall key handling on slow disk/SQLite lock. Fix: `spawn_track()` mirroring `spawn_push`, report via `TuiTaskOut`.
- **P1-4 `q`/`Esc` quit is too eager.** Anywhere outside a modal, `Esc` sets `should_quit` (`events.rs:123-125`). Users mashing `Esc` to dismiss nothing will exit the TUI. Fix: require `q` to quit and make bare `Esc` a no-op (or need double-press).
- **P1-5 Terminal-escape injection via filenames.** File paths, CIDs, operator endpoints, and feed strings render through `Span::raw/styled` with no ANSI/OSC sanitization (`ui.rs:366-372, 590-599`). A malicious tracked filename containing `\x1b]0;…` or hyperlinks could spoof the terminal. Fix: strip `\x1b`, `\x07`, `\u{9c}` (or use a `sanitize_cell` helper) at row-build time. Low likelihood, real impact.
- **P1-6 Footer under-advertises; help over-relies on memory.** `l`/`o` (account), `u` (update), `/` (lookup) exist but aren't in `footer_hint_spans`. Users never discover them without opening `?`. Fix: add `[u] Update · [/] Find` to the roomy footer, move `l`/`o` into the Overview card hint.

### P2 — polish that raises the ceiling

- **P2-1 Coarse `JoinError` reset.** `drain_tasks` (`app.rs:1295-1307`) clears *all* `*_in_flight` flags when *any* task errors. One panicking probe unlocks every duplicate-spawn guard for a tick. Fix: track task kind per handle (e.g. wrap `TuiTaskOut` with a discriminant) and clear only the failed kind.
- **P2-2 No minimum-size guard.** Layout needs 3 (header) + 10 (min content) + 3 (footer) = 16 rows; below that `table_page_height` saturates to 0 and tables render empty with no explanation. Fix: if `frame.area().height < 16` or `width < 60`, render a centered "terminal too small" message and skip tab content.
- **P2-3 No `NO_COLOR` / theme support.** Palette is hardcoded (`Cyan`/`Green`/`Rgb(30,58,138)` selection). Light-background terminals and colorblind users get low-contrast badges; latency color is the only signal besides text. Fix: honor `NO_COLOR`, add `--theme dark|light|mono`, ensure status always has a text token (already true for ONLINE/OFFLINE — extend to latency tiers).
- **P2-4 Display truncation collisions.** `file_id_hex` is `hex::encode(&file_id[..4])` (`app.rs:598`) — 8 hex chars, fine as a snippet but never labeled as truncated; `elide_hex` truncates 8…8 elsewhere. Label both ("`abcd1234…` (trunc.)") or show full on selection-detail.
- **P2-5 `main.rs` god-file.** Root CLI file owns theorrection `Cli`/`Commands` definitions, `HELP_TEMPLATE`, dispatch, and dozens of tests. Commands themselves are well split; the dispatch `match` (`main.rs:2192+`) and template are the risk. Fix: move `Commands` + dispatch into `commands/mod.rs` (or `cli.rs`), leaving `main.rs` as thin wiring.
- **P2-6 Small UX gaps:** no mouse/scroll-wheel, no in-table filter for Files/Snapshots/Operators (Explorer alone has `/`), no copy-CID key (`y`?), no visible FastCDC progress state, token tab lacks manual re-probe key, operator endpoint column fixed-width truncation, update flow keeps old binary until relaunch (correct, but footer should say so persistently).

### What failed to reproduce / not issues

- No `unwrap` panics on the render path; `hex_head` uses `get(..n)` with fallback (`ui.rs`); `window_range` clamps (`offset.min(len-1)`); scroll indices are clamped on data refresh (`clamp_table_indices`, tested).
- `refresh_local_state` swallows store errors into "Not Initialized" rather than crashing (`app.rs:643-646`) — correct fail-closed for a viewer.
- Dual `ciphervault`/`cv` binaries share one `main.rs` (`apps/cli/Cargo.toml:9-15`); `bin_name_for_argv0` + template tests keep help/completions honest.

## Recommendations (ordered)

1. Fix P1-1 (one-line data bug, high trust impact).
2. Add confirm modals for `a`/`x` (copy the update-modal lock pattern), make `Esc` non-quitting.
3. Move track-file I/O to `spawn_track` + sanitize row strings.
4. Footer: add `u` + `/`; Overview card: hint `l`/`o`; add min-size guard + `NO_COLOR`.
5. Split `main.rs` dispatch into `commands/mod.rs`; add 3 tests: confirm-modal blocks double-`a`, min-size message renders, `NO_COLOR` strips ANSI.

## Remediation applied (2026-11-06, same session)

All five ordered recommendations were implemented and verified:

1. **P1-1 file count** — `SnapshotItem.files_count: usize` → `Option<usize>`; refresh sets `None` (manifests are encrypted, per-snapshot counts unknowable without decrypt). Table renders `unknown`, modal renders `sealed files (encrypted manifest)`.
2. **Confirm modals + Esc** — new `ConfirmAction::{Anchor, Untrack{path}}` staged by `[a]`/`[x]`, resolved single-shot by `[y]/[Enter]`, cancelled by `[n]/[Esc]`; bare `Esc` no longer quits (`[q]`/`Ctrl-C` do). Help modal documents the flow.
3. **Background track + sanitize** — new `spawn_track` (`spawn_blocking` + `TuiTaskOut::TrackFinished` + `track_in_flight` guard); new `sanitize_cell` strips control chars from every untrusted render path (paths, endpoints, operator ids, feed fields, token strings, input echoes, status line).
4. **Footer/Overview/a11y** — footer gains `[u] Update` + `[/] Find` (threshold 91→115, compact keys-only mode fits 80 cols); Overview adds the `[l]/[o]/[u]/[/]` hint line; `draw` renders a `Terminal too small` fallback under 62×16; `NO_COLOR`/`TERM=dumb` degrade badge/selection/latency/tab-strip/boundary colors to text+inverse (all semantic colors keep text labels).
5. **Dispatch split + tests** — `main.rs::run` is now 6 lines delegating to `commands::run_command` (`main.rs` 3058→2672 lines; dispatch lives in `commands/mod.rs`). 5 new tests: `anchor_confirm_requires_explicit_confirm_and_fires_once`, `snapshot_modal_reports_unknown_file_count_honestly`, `tiny_terminal_explains_minimum_size`, `sanitize_cell_strips_terminal_escapes`, `no_color_strips_semantic_styles`.

**Verification:** `cargo test -p ciphervault-cli --bin ciphervault` → **222 passed, 0 failed** (48 TUI); `cargo clippy` → clean (only the pre-existing dual-binary manifest note).
