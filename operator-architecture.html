CipherVault Operator — Hardened Architecture

post-audit 2026-11-08 • Axum :PORT • strict_auth default-on • green = this audit's additions • R1–R13 all closed, suite green

Request path: wire → middleware → route → state → disk/swarm

Top to bottom. Anonymous capability reads are isolated on their own 60/min tier; the control plane needs the service token; enrollment can no longer mint fleet admins by default.

Auth model

  • • Service token: sole root for enroll/revoke/mint; constant-time compare; can't mint admins by default
  • • Sessions: Ed25519 challenge, single-use, 1h TTL, per-request enrollment + scope recheck
  • • Strict: default-on; any non-strict bypass now logs a loud warning
  • • Anonymous: recovery reads + PoS oracle by design, tier-isolated at 60/min

What changed (R1–R13)

  • • Rebuilt from source: enroll, pagination, limiter, health, join plane all present
  • • Fail-closed: voucher profile, FLEET_ADMIN grant, retention cap 36500d
  • • Isolated: recovery reads 60/min tier; metrics loopback-only
  • • Hardened: per-key challenge cap, routing-member repair, gated raw DHT puts

Still open (decisions)

  • • TLS: plaintext HTTP on 0.0.0.0 — needs reverse-proxy story or native TLS
  • • PoS freshness: caller-supplied nonces — next protocol version
  • • Retention: caps enforced, but no expiry/GC; "90-day" copy still aspirational
  • • dist/bin: copy fresh builds in before the demo
